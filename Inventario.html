Cómo se usa 

  

    
    
      
  1. Crea una zona (o abre una tuya) en Mis zonas.
    2. 
      
  2. Pulsa 📷 Escanear con la cámara y apunta al código de barras. Cada producto se suma en una sola línea; si ya estaba, verás «YA ESTABA ✔ SUMADO».
    3. 
      
  3. Para contar otra unidad del mismo producto: aparta la cámara un par de segundos o pulsa + Otra vez. Para varias unidades de golpe, pon la cantidad antes de escanear.
    4. 
      
  4. Si sale «Código no encontrado», escribe nuestro código del producto y pulsa Guardar y sumar. La próxima vez ya lo reconocerá (para todos).
    5. 
      
  5. Si un producto no tiene código de barras, usa 📖 Buscar producto y búscalo por nombre.
    6. 
      
  6. ¿Error? ↶ Deshacer, o toca la cantidad para corregirla.
    7. 
      
  7. Al acabar, pulsa ✔ Terminar y enviar zona. Si no hay internet, se enviará sola cuando vuelva.
    8. 
    

    
Todo se guarda en el dispositivo tras cada escaneo: si se cierra la app o se apaga el móvil, no se pierde nada.
